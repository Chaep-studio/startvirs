# HTML Roguelike 游戏 PRD

## 1. 项目概述

- **项目名称**: Browser Roguelike
- **类型**: 回合制地牢探索游戏
- **核心玩法**: 玩家在随机生成的地牢中探索、战斗、收集装备，击败 Boss 通关
- **目标用户**: 休闲玩家、Roguelike 爱好者

## 2. 核心功能

### 2.1 地图系统
- 房间制地图（5x5 格子，每个房间随机事件/敌人/奖励）
- 房间类型：普通房、精英房、商店、宝箱房、Boss房
- 相邻房间用门连接，玩家点击移动

### 2.2 角色系统
- **属性**：生命值、攻击力、防御力、金币
- **等级**：击败敌人获得经验，升级提升属性
- **装备**：武器（+攻击）、防具（+防御）、饰品（特殊效果）

### 2.3 战斗系统
- 回合制：玩家先手，选择攻击/防御/使用道具
- 伤害公式：max(1, 攻击方攻击力 - 防御方防御力)
- 暴击率 10%，暴击伤害 200%

### 2.4 敌人系统
- 普通怪：哥布林、骷髅、史莱姆
- 精英怪：高属性，带特殊技能
- Boss：每层最后一个房间，强大且有特殊机制

### 2.5 物品系统
- **消耗品**：红药水（恢复生命）、蓝药水（恢复能量/特殊技能）
- **装备**：随机属性白/绿/蓝品质
- **金币**：用于商店购买

### 2.6 存档系统
- LocalStorage 自动保存
- 可选择新游戏或继续

## 4. 验收标准

1. ✅ 地图正确生成，相邻房间可访问
2. ✅ 玩家可移动、进入房间、触发事件
3. ✅ 战斗系统正常运作（攻击、防御、伤害计算）
4. ✅ 装备系统可用（穿戴、卸下、属性加成）
5. ✅ 商店系统可用（购买道具/装备）
6. ✅ 3 层地牢可通关，Boss 战可完成
7. ✅ 游戏结束后可重新开始
8. ✅ 存档/读档功能正常
